The 5 mods to the Reaction Time Tester I did were:
1. Change of color between tests
2. An Average mode that does 5 tests and gives you the average of those 5 tests
3. A ranking system based on your best reaction speed
4. A color matching mode where you react to the right color instead of any color
5. A Quick Time Event mode were you quickly put in a sequence of "WASD" instead of just a click
